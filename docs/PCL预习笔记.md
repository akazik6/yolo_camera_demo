# PCL 预习笔记

## 1. 什么是点云

点云是空间中大量离散点的集合，每个点通常包含三维坐标 `(x, y, z)`，还可以带有强度、颜色、时间戳等信息。它由激光雷达、深度相机、结构光等设备对物体表面采样得到，是对真实场景的稀疏几何描述。

与普通图像的区别：

| 对比项 | 图像 | 点云 |
| --- | --- | --- |
| 数据维度 | 2D 像素阵列，规则网格 | 3D 离散点，无序 |
| 每个元素 | 颜色（RGB/灰度） | 坐标 + 强度/颜色等 |
| 成像条件 | 依赖光照，有透视投影 | 主动测距，不受光照影响 |
| 尺度 | 丢失深度，尺度不确定 | 有真实物理尺度（米） |
| 遮挡 | 遮挡后不可见 | 可保留部分空间结构 |
| 处理难点 | 纹理、光照变化 | 无序、稀疏、噪声、数据量大 |

## 2. PCL 主要解决什么问题

PCL（Point Cloud Library）是一个开源的 C++ 点云处理库，提供从数据读写到高层识别的完整工具链：

- **I/O**：读写 PCD、PLY、OBJ 等格式，连接 Kinect、Velodyne 等设备；
- **滤波**：去除噪声、离群点，限制坐标范围；
- **降采样**：在保留几何结构的前提下减少点数；
- **分割**：把点云拆成地面、墙面、物体等部分；
- **聚类**：把属于同一物体的点聚成一簇；
- **特征与配准**：法向量、FPFH 等特征，ICP 等配准算法；
- **识别与重建**：模型拟合、位姿估计、表面重建、可视化。

PCL 常与 ROS/ROS 2 配合使用，是激光雷达感知方向的基础工具。

## 3. 四个基本处理

| 处理 | 作用 | 常用算法 | 关键参数 |
| --- | --- | --- | --- |
| 滤波 | 去掉噪声点、离群点、无效点 | StatisticalOutlierRemoval、RadiusOutlierRemoval、PassThrough | 邻域点数、标准差倍数、半径、坐标范围 |
| 降采样 | 减少点数、统一密度、提升速度 | VoxelGrid | 体素边长（leaf size） |
| 分割 | 按几何/语义把点云分成若干部分 | RANSAC 平面拟合、区域生长、欧式聚类 | 距离阈值、法向量夹角、最小簇点数 |
| 聚类 | 把相邻点归为同一目标 | EuclideanClusterExtraction、DBSCAN | 聚类半径、最小/最大簇点数 |

- **滤波**：激光雷达点云里常有飞点、雨雾噪声和远处稀疏点，先滤波可以显著改善后续分割效果。
- **降采样**：体素栅格把空间划分成小立方体，每个立方体用一个点代表，点数下降一个数量级，形状基本不变。
- **分割**：最典型的是用 RANSAC 拟合地面平面，把地面点去掉，只保留障碍物。
- **聚类**：对非地面点做欧式聚类，距离小于阈值的点连成一簇，每一簇对应一个候选目标。

## 4. 在激光雷达感知中的用途

典型链路：**点云采集 → 预处理滤波 → 地面分割 → 聚类 → 特征提取与分类 → 目标跟踪**。

- 滤波和降采样保证实时性，减少无效计算；
- 地面分割把可行驶区域和障碍物分开，是后续检测的基础；
- 聚类给出候选目标的位置和尺寸，供分类网络或规则判断使用；
- 结合多帧跟踪可以得到目标的速度和运动轨迹，用于避障和规划。
